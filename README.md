# some-candles-digital-assistant
Some Candles (https://shinabarger.github.io/some-candles-digital-assistant/) is an assistant for running some candles digitally and tracking and sharing actively with players and if running digitally over a screenshare or other service. 

Some Candles is a browser companion for tabletop horror games built around a dwindling set of candles. It tracks the communal dice pool, candle count, scene progression, and narration rights so the table can stay focused on the story instead of bookkeeping. Open the file in any browser and you are ready to play, no installation and no server required.

The app also includes a threat generator with a hundred prompts for the GM to draw from when building a scenario, along with a running log that records every roll and its outcome in plain language. It is built as a single file, so anyone at the table can save it and run it themselves without any setup.
